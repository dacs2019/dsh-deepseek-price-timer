⏱️ dsh-deepseek-price-timer

Live DeepSeek peak/off-peak pricing widget for the DeepSeek Harness Web GUI. Detects your timezone, shows local vs UTC, and updates prices from the official page.

Status at a glance

🔴 PEAK — 2× rate 🟢 OFF-PEAK — half price 🟡 FLAT — pre-cutover countdown

Peak hours: 01:00–04:00 and 06:00–10:00 UTC. New pricing effective 2026-08-16 16:00 UTC.

Features

  • Live official prices (fetched every 30 min, embedded fallback)
  • Local clock + UTC clock with detected offset
  • 24h timeline in your local time (green off-peak / red peak)
  • Session header pill + composer dock widget
  • Live session cost estimate from real token usage
  • Window-change alerts, collapse mode, tooltips, ES/EN i18n
  • Self-update: downloads, validates and applies new versions, then restarts

Install

git clone https://github.com/dacs2019/dsh-deepseek-price-timer.git
cd dsh-deepseek-price-timer
npm run install:profile   # auto-detects Windows / Linux / macOS

Then restart dsh web and reload the page.

Configuration

  • DSH_DSPT_REPO — your repo (owner/repo) to enable the update checker
  • DSH_DSPT_PEAK_WINDOWS — override peak windows without touching code
